# 文言の型

- 語尾は「です・ます」体の短文。見出しは名詞止め。
- 数値は半角、桁区切りカンマ、単位は後置（`¥1,234,567` は ¥ 前置）。増減は `+12.3%` `−4.1pt`（マイナスは U+2212）、矢印は `▲`/`▼` を数値の前に付ける。
- 絵文字は使わない。アイコンは lucide のみ、見出しの左に 16px。
- ボタンは動詞で終わる: 「保存」「追加」「完了して送信」「削除」。「OK」「はい」は使わない。

## 確認ダイアログ（破壊操作のみ）
- タイトル: 「◯◯を削除しますか？」
- 本文: 何が消えるか1文 + 戻せないこと1文。「この操作は取り消せません。」
- ボタン: 右に破壊「削除」(destructive)、左に「キャンセル」(ghost)。

## トースト
- 成功: 「保存しました」「送信しました」 3秒。
- 取り消し可: 「タスクを完了にしました」+ 「元に戻す」 6秒。
- 失敗: 「保存できませんでした。もう一度お試しください」 手動で閉じる。

## 保存状態（右上1箇所）
- 「保存中…」→「保存済み 15:56」→ 失敗時「保存に失敗 再試行」

## 空状態（2文）
- 1文目: なぜ空か。「今週のタスクはまだありません。」
- 2文目: 次にすること。「下の入力欄から追加できます。」
- 初回ガイド変種: 見出し + 3手順の番号リスト + 主ボタン1つ。

## 必須項目
- 赤アスタリスクではなく、ラベル末尾に「（必須）」。任意は何も付けない。

# DVB リファレンス画面

`index.html` を開く。上部バーで 画面（案件別まとめ（ボード） / 案件別まとめ（1案件） / 日報）× 状態（通常 / 空 / 読み込み / エラー、日報は + 送信済み）× 幅（1440 / 1280）× ナビ（248 / 56）を切り替える。URL ハッシュに同期する（例: `#screen=board&state=empty&w=1280&nav=min`）。

## 画面と現行の対応

| 画面 | 現行パス | 主な変更 |
|---|---|---|
| 案件別まとめ（ボード）= GG 週次案件ボード | `/reports/projects/comparison` | ナビ「案件別まとめ」の着地画面（サイドバーに個別項目を持たない）。thead blue-900 → muted。14 列を「主値＋増減」2段セルで 8 列 1,104px に（先週粗利／ROAS は列にせず title ツールチップ）。1440 − ナビ 248 で横スクロール無し。担当者負荷ストリップは「今週タスクを持つ案件数」（チップで絞り込み、末尾に「担当者が付いていない案件 N件」）→ KPI 3 枚 → 表。行頭のシェブロンで展開（備考・検証CP要約）。行内タスク追加（Enter / Esc） |
| 案件別まとめ（1案件） | `/reports/projects` | ボードから案件名で開く詳細。先頭に「← ボードへ戻る」。今週のタスクは KPI 直下の独立セクション。 紺 + 青の帯を廃止。KPI 4 枚。CPN 表・広告セット表は compact 密度。textarea の amber-50 を白に。保存状態は右上1箇所 |
| 日報 | `/mbo` | 青帯 → PageHeader。自動保存注記・「完了して送信」1ボタンは維持。送信後は readOnly + 送信済み表示 |

## 操作できるもの
- ボード: 担当者チップで絞り込み、列ヘッダで並べ替え、チェックで完了（取り消しトースト）、×で削除（ConfirmDialog）、「タスクを追加」で行内入力
- 案件別: 担当者タブ、textarea 入力で「保存中… → 保存済み」、タスク追加行
- 日報: 入力で自動保存表示、「完了して送信」→ 確認 → 送信済み、「本日休み」トグル

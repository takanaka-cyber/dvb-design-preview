# DVB design preview

DVB（AXIS 社内ツール）の新デザイン確認用の静的プレビュー。モックデータのみで、本番データ・本番画面は含まない。
入口: `ui_kits/dvb/index.html`

- 既定は「実機モード」: ツールバー無し・枠無しで、ブラウザ幅（スマホなら端末幅）いっぱいに描画する。画面移動はアプリ内のサイドバー／ドロワー。
- URL 末尾に `&bar=1` を付けると、画面・状態（空／エラー等）・幅・ナビ幅を切り替えるキット用ツールバーが出る。
- 直接指定: `#screen=weekly&state=empty` のように `screen` と `state` を付ける。
